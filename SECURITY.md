# Güvenlik bildirimi

Bir güvenlik sorunu için proje sahibine özel kanaldan ulaşın. GitHub deposunda özel güvenlik bildirimi etkinleştirildiğinde **Security → Report a vulnerability** düğmesini kullanın. İlk bildirimde etkilenen sürümü, platformu, beklenen güvenlik sınırını ve gözlenen etkiyi belirtin. Kullanıcılara ait parola, tanımlayıcı, oturum adresi veya erişim belirteci eklemeyin.

Henüz yayımlanmamış sürümler ve destek süresi ilan edilmemiş paketler önizleme statüsündedir. Yayınlanan sürümlerin güvenlik kapsamı, paketin sürüm notlarında belirtilir. Yerel doğrulama ve tehdit varsayımları için [tehdit modeline](docs/threat-model.md) bakın.
